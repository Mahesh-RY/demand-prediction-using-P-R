# demand-prediction-using-P-R
Predicted store item demand trends using a Kaggle dataset. After cleaning and aggregating sales data, a polynomial regression model (degree 3) was applied to capture nonlinear growth patterns. Achieved an R² score above 0.9, effectively modeling seasonal sales variations and forecasting future demand.
